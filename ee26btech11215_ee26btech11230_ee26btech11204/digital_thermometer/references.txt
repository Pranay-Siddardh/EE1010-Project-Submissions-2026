2. POTENTIOMETER — PINOUT AND WORKING PRINCIPLE

   Description:
   A potentiometer is a three-terminal variable resistor. Its two outer terminals connect across a supply and ground, while the wiper provides an adjustable voltage. In this project, the potentiometer is used to adjust the LCD contrast.

   Arduino LCD Tutorial — Potentiometer wiring:
   https://docs.arduino.cc/learn/electronics/lcd-displays/

   Arduino LiquidCrystal Library Example:
   https://github.com/arduino-libraries/LiquidCrystal/blob/master/examples/HelloWorld/HelloWorld.ino

6. NUMPY POLYFIT — QUADRATIC LEAST-SQUARES CALIBRATION

   Description:
   NumPy documentation for polynomial fitting using least squares. The project uses a second-degree polynomial to approximate the relationship between measured voltage and temperature:

       T = aV² + bV + c

   The coefficients a, b, and c are obtained from experimental voltage-temperature data using a quadratic polynomial fit.

   NumPy polyfit Documentation:
   https://numpy.org/doc/stable/reference/generated/numpy.polyfit.html

   NumPy Polynomial Fitting Documentation:
   https://numpy.org/doc/stable/reference/generated/numpy.polynomial.polynomial.polyfit.html
